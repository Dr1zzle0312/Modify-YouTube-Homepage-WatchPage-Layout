介绍

用于优化首页和视频页的布局。

1. 首页视频卡片根据窗口宽度自适应布局 最多一列5个。

2. 视频页右侧推荐视频收窄宽度，让视频播放器更大。

3. 评论区现在会更加居中显示，改善评论过于靠右的问题，字体也更大。可以修改居中的位置和字体大小。

代码已同步至[Greasy Fork](https://greasyfork.org/zh-CN/scripts/596643-modify-youtube-watchpage-layout-modify-youtube-homepage-layout?locale_override=1)

使用
1. 使用chrome浏览器安装[Tampermonkey](https://www.tampermonkey.net/)插件；2. 在[Greasy Fork](https://greasyfork.org/zh-CN/scripts/596643-modify-youtube-watchpage-layout-modify-youtube-homepage-layout?locale_override=1)上安装该脚本。
