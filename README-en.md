# Introduction

This script optimizes the layout of the homepage and video playback page.

1. Video cards on the homepage adapt responsively to window width, with a maximum of 5 cards per row.
2. The recommended video sidebar on the video page is narrowed to enlarge the video player.
3. The comment section is now more centered to fix the issue where comments were positioned too far to the right. Font size is also increased. You can adjust the centering offset and font size.

The script has been published to [Greasy Fork](https://greasyfork.org/zh-CN/scripts/596643-modify-youtube-watchpage-layout-modify-youtube-homepage-layout?locale_override=1)

# Usage

1. Install the [Tampermonkey](https://www.tampermonkey.net/) extension for Chrome;
2. Install this script from [Greasy Fork](https://greasyfork.org/zh-CN/scripts/596643-modify-youtube-watchpage-layout-modify-youtube-homepage-layout?locale_override=1).
